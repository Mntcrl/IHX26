# Policy reference fixtures (galaxy-geometry-view/v1)

Generated by `geometry-tool fixtures --out test-vectors/policy` (crate `galaxy-geometry`, module `fixtures`); do not edit by hand. Each file is one GeometryView (spec §20) whose `expected` object is the reference engine's §8.8 report under the policy noted below. Consumed by the circuit differential tests (`circuits/tests/geometry/policy.test.mjs`) and checked by `cargo test -p galaxy-geometry --test policy_fixtures`.

All sensor data is synthetic (ray-cast scenes, `synthetic-*`/`room-*`) or hand-constructed (`plane-*`, `extreme-*`); none comes from a device. `room-*` fixtures start from the passing synthetic room capture and change one input. `hyp_idx` is challenge-derived except where a description says it is overridden. `uj`/`vj` in `pairs` are metadata (decimal strings, null when Q_z ≤ 0).

Default-policy fixtures (top-level `*.json`): policy `galaxy-pc-v1m`, policy_id `4f6851de283944b42ddc10763da49382979778aa72213d6d9ca2a7b56962a882`.
